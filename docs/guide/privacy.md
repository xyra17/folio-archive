# 数据与隐私

[返回 README](../../README.md)

本说明对应当前源码行为。拾页使用本地资料库，没有用于托管归档正文的拾页云服务。

## 数据保存在哪里

| 数据 | 位置或方式 |
| --- | --- |
| 导出的 PDF / Word / Markdown / HTML / ZIP | 默认在系统文稿目录的「拾页归档」，可修改 |
| 任务、设置、模型密钥的加密值 | Electron 用户数据目录内的 SQLite 数据库 |
| 来源证据与检查点 | 用户数据目录内的任务检查点 |
| 来源登录状态 | 应用独立的持久化浏览器会话 |
| 旧导出文件 | 任务目录的历史备份 |

应用的包名为 `folio-archive`，用户数据目录由 Electron 与操作系统决定；macOS 默认通常位于 `~/Library/Application Support/folio-archive/`。开发时可用 `FOLIO_DATA_DIR` 指定独立目录。

模型密钥使用 Electron `safeStorage` 加密；系统加密不可用时应用拒绝保存新密钥。这不表示整份数据库、登录会话、检查点或导出文件都已加密。备份时应按个人资料妥善保管。

## 什么时候会联网

1. **采集来源**：打开你提供的网页，加载其脚本、图片和其他资源；来源网站可能使用自己的分析、Cookie 或第三方服务。
2. **AI 辅助检查**：由你填写模型请求地址、模型名与密钥，并为任务开启检查。正文对照会发送相关来源证据和提取结果；页面检查会发送所选页面截图，受调用预算限制。
3. **模型连接测试**：点击测试时会向配置的模型端点发送测试请求。
4. **应用更新**：配置发布渠道后，手动检查、下载和安装更新时连接该渠道。
5. **外部链接**：主动打开原文或其他外部链接时，由相应浏览器访问。

没有配置、启用 AI 时，基础采集、排版与规则检查不会向模型服务发送正文。模型服务的数据处理规则取决于你选择的提供方。

应用会启动绑定本机地址的演示内容服务。它用于「试一份示例」，不用于对外托管个人资料。

## 剪贴板与诊断

点击「粘贴链接」时读取剪贴板。应用不会为了保存功能持续监视剪贴板。

脱敏诊断包由用户主动生成，只包含处理阶段、计数、问题代码等诊断信息，不包含归档正文、密钥和完整私密来源地址，也不会自动上传。对外分享前仍建议自行检查文件内容。

## 清理和备份

- 移除资料库记录会保留导出文件。
- 选择同时移除文件时，归属该任务的导出目录和检查点移入系统废纸篓。
- 设置中清理来源会话会退出相关来源登录；操作前需结束或暂停任务。
- 删除或卸载应用本身不代表导出文件与用户资料目录已清除。
- 备份时退出应用，再复制资料库和导出目录；不要把自己的资料库、Cookie 或检查点提交到 GitHub。

安全问题报告方式见[安全说明](../../SECURITY.md)。
