# 使用指南

[返回 README](../../README.md)

## 保存一篇文章

在首页粘贴 HTTP / HTTPS 链接，选择格式，点击「保存到电脑」。多个链接每行一个，最多 30 个。默认导出 PDF，可以多选其他格式。

示例来源：[Anthropic 的上下文工程文章](https://www.anthropic.com/research/effective-context-engineering-for-ai-agents)。公开仓库只展示保存界面，不分发这篇文章的全文导出文件。

尚无资料时，可用「试一份示例」体验本机演示文章。演示内容由应用本机服务提供，不需要访问第三方网站。

## 排版和内容范围

展开「保存设置」：

- **PDF / Word 排版**：清爽阅读、书刊印刷、技术手册、杂志精选。可预览整页或适合宽度的效果。
- **内容范围**：先确认章节、设置起始标题，或按标题排除小节。起始标题作用于首个所选章节。
- **AI 辅助检查**：默认关闭。基础保存无需模型密钥，配置与数据发送范围见[隐私说明](privacy.md)。

HTML 使用独立的网页阅读版，带章节目录、阅读进度、深色模式和代码复制。只选 HTML 时应用内显示网页预览；同时选择 PDF 时优先显示纸张预览。

## 登录和访问限制

需要登录时，点击任务提供的来源网页入口，在独立窗口内完成登录，然后继续保存或重新检查。应用使用自己的来源会话，不自动读取其他浏览器的登录信息。

有账号并不等于有导出权限。需要会员、验证码、无权限或禁止导出时，应先在原站确认允许的操作。保存完成也不能证明来源的全部内容都已归档。

## 查找和管理资料

在「已保存」中搜索本地正文，使用集合和标签整理资料。默认导出到系统文稿目录的「拾页归档」文件夹，设置中可以修改。

文件夹使用任务创建日期，按本机时区命名：

```text
拾页归档/
├── 2026-10-30文章标题/
│   ├── 文章标题.pdf
│   ├── 文章标题.docx
│   ├── 文章标题.md
│   ├── 文章标题.html
│   ├── 文章标题_离线资料包.zip
│   ├── assets/
│   ├── 归档报告.json
│   └── 阅读说明.md
└── 2026-10-30文章标题 (2)/
```

文件随所选格式和实际素材变化。HTML 内嵌图片，可单独移动；Markdown 的图片保存在 `assets/`，迁移时请一起保留。ZIP 用于整体备份和搬运。

同一天的同名任务追加序号，不覆盖现有目录。重试和重新导出继续使用原文件夹；历史版本的目录名也会保留。

## 暂停、重试与重新导出

- 暂停后可继续，已完成的检查点会复用。
- 取消会保留已保存内容。
- 失败素材可单独重试；请同时查看保存详情中的缺失提示。
- 「用已保存内容重新导出」复用本地证据，不重新访问正文来源。
- 重新采集会访问来源，比较内容变化，并保留旧导出文件的历史备份。

仅移除资料库记录时，导出文件保留在磁盘。选择同时移除文件时，任务专属目录与检查点移入系统废纸篓；清空废纸篓前可恢复。

## 常见问题

### 为什么保存结果有提示？

网页可能有未加载图片、组件、合并表格或访问限制。「已保存 · 有提示」说明仍需核对相关内容。归档报告会记录已知问题，不把有文件等同于内容完整。

### 保存后能完全离线吗？

导出的文件可以离线打开。HTML 内嵌成功保存的图片；Markdown 需要本地素材目录。点击原文链接、重新采集或启用远端模型服务时仍需网络。

### 可以保存飞书等在线文档吗？

应用会尝试识别可访问的在线文档及章节结构。登录状态、文档权限和平台页面变化都会影响结果；复杂组件可能只能保留截图或记录缺失。请按原站允许的方式使用。

### 什么时候需要 AI？

基础保存、排版和规则检查不需要 AI。可选 AI 用于对照正文证据和检查所选页面，可能产生你配置的服务费用。页面检查需支持图片的模型，连接测试通过不代表视觉能力已验证。

### 为什么 PDF 原件没有转成 Word？

当前优先保存来源 PDF 原件，不做 PDF 反向转换和扫描件 OCR。网页正文生成 Word 是另一条处理流程。

### 快捷键是什么？

macOS 首页使用 `⌘ Enter` 保存，`⌘ N` 新建。点击「粘贴链接」时才读取剪贴板。
