让好内容，随时可读

拾页 · 排版示例约 2 分钟阅读

从一篇文章开始，建立属于自己的离线资料库。无论是工作中反复查阅的指南，还是想慢慢读完的长文，都可以保留原文的结构，用更适合阅读的方式重新打开。

为阅读留一点空间#

标题帮助定位，段落承载思考，留白让阅读有了停顿。把一篇长文整理成适合自己的版式，减少视觉干扰，也让重点更容易被找到。

收藏的意义，是在需要的时候，重新找到那些值得思考的内容。

选择合适的保存方式#

文件格式适合的时刻
PDF安静阅读、打印与分享
Word继续编辑、批注与整理
Markdown收入笔记、连接新的想法
HTML直接打开，离线阅读与分享

代码保留缩进与换行，内容结构也可以继续使用：

javascript
const archive = {
  title: "值得反复阅读的文章",
  formats: ["pdf", "docx", "md", "html"],
  offline: true
};

// 内容只保存一次，可以生成多种格式。
await save(archive);

长文也可以轻松定位#

章节目录会根据正文标题自动生成。大屏幕上，它停留在左侧；切换到手机，目录收进文章上方，需要时再展开。页面顶部的细线记录当前阅读位置。

原文结构，完整保留#

  • 标题保留清晰的层级，段落保持原有顺序。
  • 代码保留缩进与换行，点击按钮即可复制。
  • 表格在窄屏内独立滚动，阅读正文不受影响。

把阅读带到离线#

成功保存的图片直接嵌入 HTML。把这一个文件移到另一个文件夹，或发送到另一台电脑，正文与图片仍然可以一起打开；页面也不需要额外下载字体、样式或脚本。

阅读之外，继续使用#

需要做笔记时，选择 Markdown；需要继续编辑，选择 Word；需要固定纸张版式，选择 PDF。HTML 则适合随时打开、快速定位和离线阅读，浅色与深色阅读也可以随手切换。

每一份整理，都是为了下一次更容易找到。
